# EmStat-Pico-Project
The Emstat-Pico PCB utilizes PalmsensBV (Houten, Netherlands) commerical potentiotat package in an arduino framework. This enables us to convert amperometric and voltmmateric outputs into clinically relevant outputs like concentration.
